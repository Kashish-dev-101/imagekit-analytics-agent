# version-control/

Archived older versions of the prompt and guardrails, each paired with the example output they produced.

Useful for understanding why a rule was added or why the prompt changed.

## Naming convention

`prompt-v[N].md` — archived prompt version  
`guardrails-v[N].md` — archived guardrails version  
`[account]-[period]-prompt-v[N].md` — output produced by that prompt version

See `../prompt.md` and `../guardrails.md` for the latest.
