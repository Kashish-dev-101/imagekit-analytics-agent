Archived older versions of the prompt and guardrails, each paired with the example output they produced, plus prompt-development test runs in `test/`.

Restructure history and removed-CLAUDE.md-section notes now live in `../status.md` rather than as separate files here.

Useful for understanding why a rule was added or why the prompt changed. Only this README is tracked in git — everything else here is local-only.

## Naming convention

`prompt-v[N].md` — archived prompt version
`guardrails-v[N].md` — archived guardrails version
`[account]-[period]-prompt-v[N].md` — output produced by that prompt version
